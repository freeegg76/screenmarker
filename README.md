# ScreenMarker

마우스로 Windows 화면 위에 표시하고, 내장 화이트보드에서 내용을 작성·저장하는 프로그램입니다.

## 실행

Python 3.10 이상에서 프로젝트 폴더의 터미널을 열고 실행합니다.

```powershell
py -m pip install -r requirements.txt
py ScreenMarker.py
```

## 사용

- 도구막대에서 형광펜, 사각형, 원을 선택하고 화면 위에서 마우스로 그립니다.
- 색상 버튼으로 색을 고르고 굵기 슬라이더로 선 굵기를 조절합니다.
- `되돌리기`는 마지막 도형 또는 선을 지우고, `전체 지우기`는 모든 표시를 지웁니다.
- `입력 통과`를 누르면 표시를 유지한 채 아래 프로그램을 클릭할 수 있습니다. 다시 그리려면 `그리기 모드`를 누릅니다.
- `화이트보드`를 누르면 화면 최대화 보드 창이 열립니다. 화살표 선택 도구로 개체를 선택해 이동하거나 `Delete` 키로 삭제할 수 있고, 펜, 부분/라인 지우개, 사각형, 타원, 선, 텍스트 입력과 되돌리기를 사용할 수 있습니다.
- 텍스트 도구로 보드를 클릭하면 그 자리에서 바로 입력합니다. `Esc`, `Ctrl+Enter` 또는 보드 바깥 클릭으로 입력을 마칩니다. 기존 텍스트를 클릭하면 다시 편집합니다.
- 도구막대의 글꼴 목록과 글자 크기(px)로 텍스트의 글꼴과 크기를 정합니다. 입력 중이거나 텍스트·도형이 선택된 상태에서 바꾸면 해당 개체에 바로 적용됩니다.
- 개체를 그리면 바로 선택된 상태가 됩니다(지우개 제외). 선택된 개체의 테두리 핸들 8개를 끌면 크기를 바꿀 수 있고, 텍스트는 글자 크기가 함께 바뀝니다.
- 사각형이나 타원을 선택한 뒤 `Enter`를 누르거나 더블클릭하면 도형 안에 문자를 입력할 수 있으며, 문자는 도형 가운데에 줄바꿈되어 표시됩니다.
- 화이트보드는 `.sboard` 파일로 저장하고 다시 열 수 있으며, `PDF 내보내기`로 가로 A4 PDF를 만듭니다.
- 보드에 저장되지 않은 변경이 있으면 창을 닫거나 프로그램을 종료할 때 저장, 저장 안 함, 취소를 선택할 수 있습니다.
- 도구막대의 `닫기`를 누르면 프로그램을 종료합니다.
- 전역 단축키 `Ctrl+Alt+W`로 그리기/입력 통과 모드를 전환하고, `Ctrl+Alt+Q`로 종료합니다.

## EXE 만들기

Windows에서 `build.bat`을 실행하면 필요한 패키지를 설치하고 `dist\ScreenMarker.exe`를 만듭니다.
